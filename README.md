# ヨミテ（Yomite）— 引き継ぎ書

ボードゲームのインスト（ルール説明）を、**声・すごろく・紙芝居**で初心者に伝えるアプリ。
Dized の"軽量・親切"版。まずWebアプリ、次にPWA（ホーム画面に追加できる）へ。

このリポジトリは、Claude とのチャットで作った試作（アーティファクト）を Claude Code に
引き継ぐためのもの。**最初にこの README → HANDOFF.md → PWA_SETUP.md の順で読んでください。**

---

## ファイル

- `yomite.jsx` … アプリ本体（Reactの単一コンポーネント）。これが全部入り
- `HANDOFF.md` … Webアプリ化の手順・作り替えが要る2か所・データ構造・ロードマップ
- `PWA_SETUP.md` … PWA化（ホーム画面に追加）の手順
- `yomite-icon.svg` … アプリアイコンの元データ
- `README.md` … このファイル

---

## まず動かす

Claude Code にこのフォルダで頼めばOK（詳細は HANDOFF.md）。

```
npm create vite@latest yomite -- --template react
cd yomite
npm install
```

- `yomite.jsx` の中身を `src/App.jsx` に貼り替え、`src/index.css` は空にする
- `npm run dev` で起動

追加ライブラリは不要（React＋ブラウザ標準機能で動く）。

---

## いちばん大事：アーティファクト専用で「作り替えが要る」2か所

1. **保存（`window.storage`）** → `localStorage` に置き換える（HANDOFF.md 2-A に手順とコード）
2. **AI呼び出し（ルールQ&A・AI紙芝居生成）** → 今はアーティファクト内でキー無しで動いているだけ。
   本番では **APIキー＋小さなサーバー（中継）** が必要。**キーを画面側コードに置かないこと**
   （HANDOFF.md 2-B）

この2つ以外（音声・紙芝居・すごろく・編集・PDF・CSV取り込み）はそのまま動く。

---

## いま出来ていること

- 入り口で「はじめての人／インストする人」を選んで画面を出し分け
- 検索つきカタログ（人数・年齢・メカニクスで絞り込み）
- 紙芝居（1枚ずつ手動送り＋読み上げ）／すごろく（コマが進みながら読み上げ）
- ルールQ&A（そのゲームのルールだけを根拠にAIが回答）
- 台本エディタ（5項目＋メタ情報、新規作成・複製・削除、自動保存）
- **AIで紙芝居の自動コマ割り**（台本 → 紙芝居を生成）
- **スプレッドシート（CSV/TSV）でまとめて取り込み**
- PDF書き出し
- **音声/画像の差し込み口**（高品質TTS・AI画像・実物写真を後から差せる土台）

サンプル4ゲーム：ナンジャモンジャ／ごきぶりポーカー／ハゲタカのえじき／ウイングスパン。

### 正確さ・口調の方針（重要）
このアプリはルールを教えるので、**間違い＝信頼崩壊**。AIには「台本本文にないことは
足さない・作文しない／数や条件は本文の表現を優先／曖昧なら断定しない」を指示済み。
口調は「やさしく正確なゲームマスター」で統一。台本は"作る"より **貼って整える** 方向が安全。

## この後の道すじ

1. Webアプリとして動かす（HANDOFF.md）
2. 保存を localStorage に、AIをサーバー中継に置き換え
3. PWA化（PWA_SETUP.md）＝ホーム画面に追加・オフライン対応
4. 高品質TTS／AI画像／実物写真を実接続（バックエンド）
5. 「ルールを貼ると台本に整形」する取り込み、口調プリセット、お気に入り 等（ロードマップ）
