# ボードゲームひろば（仮）運営チーム

このサイト（`hub/` のボードゲームひろば）を運営するための、AIエージェントによる
「会社」です。**メインエージェント1人＋サブエージェント6人**の体制で回します。

## 組織図

```
                    ┌──────────────┐
   ユーザー ────────▶│  secretary    │  メインエージェント（一流のキャリアウーマン秘書）
  （あなた）         │  段取り・進捗管理│  指示を受け取り、担当へ振り分け、進捗を管理し報告
                    └──────┬───────┘
   ┌───────┬───────┬──────┼──────┬───────┬───────┐
   ▼       ▼       ▼      ▼      ▼       ▼
┌────────┐┌────────┐┌────────┐┌────────┐┌────────┐┌────────┐
│ staff-1 ││ staff-2 ││ staff-3 ││ staff-4 ││ staff-5 ││ staff-6 │
│ 校正校閲 ││ ゲーム  ││ 宣伝広報 ││ 法務部  ││ UI/UX  ││ ビジュアル│
│ のプロ   ││ 制作者  ││ ・SNS   ││ （法務） ││（使い勝手）││ アイコン │
│（文章）  ││（正誤）  ││        ││        ││        ││（造形）  │
└────────┘└────────┘└────────┘└────────┘└────────┘└────────┘
```
> staff-5（UI/UX＝使い勝手・情報設計）と staff-6（ビジュアル＝アイコン・配色の造形）は
> 隣どうしで協働。前者は「使いやすいか」、後者は「見た目・アイコンが美しく伝わるか」。

## 役割分担

| エージェント | 役割 | 状態 |
|-------------|------|------|
| **secretary** | 一流のエグゼクティブ秘書（バリバリのキャリアウーマン）。受付・割り振り・進捗管理・品質の門番・報告。仕事ができて進捗管理に厳しい | 稼働中 |
| **staff-1** | 校正・校閲のプロ（元・大手出版社の編集長）。文章の質だけを審査（重複・表記ゆれ・構成・読みやすさ）。内容の正誤は見ない | 稼働中 |
| **staff-2** | プロのボードゲーム制作者（世界で活躍）。ルールの正確さ・抜け・例外・教える順番を検証。文章の巧拙は見ない | 稼働中 |
| **staff-3** | 宣伝・広報／マーケティングのプロ。お客さんを引きつけるキャッチコピーと、Instagram・X・Threads の SNS 運用が得意 | 稼働中 |
| **staff-4** | 法務部（企業法務・知財）。著作権・商標の扱い、宣伝表現の適法性、免責・規約・プライバシー、権利者対応を審査。リスクを高/中/低で色分けし代替案を出す | 稼働中 |
| **staff-5** | UI/UXデザインのプロ（モバイルファースト）。情報設計・操作性（タップ領域・状態）・視覚的階層・レスポンシブ・アクセシビリティ・一貫性・導線を、実機幅で観察して審査。優先度つきで Before→After を出す。文章の訴求や質は見ない | 稼働中 |
| **staff-6** | ビジュアル／グラフィックデザイナー（アイコンの専門家）。台本カバーのエンブレム（線画SVG）・UIアイコンの設計、共通アイコン集（無料／PRO解禁）の拡充、配色・視覚トーン・一貫性を担当。使い勝手（staff-5）ではなく“ビジュアルの造形・アイコン”を作る | 稼働中 |

## 指示の流れ

1. **ユーザー → 秘書**：やってほしいことを秘書に伝える。
2. **秘書が整理**：曖昧な点を確認し、タスクに分解する。
3. **秘書 → 担当**：各タスクを適した担当へ、目的・成果物・制約つきで委任する。
4. **担当 → 秘書**：成果物と、判断に迷った点を返す。
5. **秘書 → ユーザー**：結論から簡潔に報告する。

## エージェントの実体とスキル

各エージェントは Claude Code のサブエージェントとして `.claude/agents/` に、
各自の得意技（スキル）は `.claude/skills/` に定義しています
（このファイルは人間向けの概要）。

| エージェント | 定義ファイル | 割り当てスキル |
|-------------|-------------|---------------|
| secretary | `.claude/agents/secretary.md` | `progress-management`（段取り・進捗管理・報告） |
| staff-1 | `.claude/agents/staff-1.md` | `proofreading`（校正・校閲） |
| staff-2 | `.claude/agents/staff-2.md` | `boardgame-rule-check`（ルール検証） |
| staff-3 | `.claude/agents/staff-3.md` | `promo-copy`（キャッチコピー・SNS運用） |
| staff-4 | `.claude/agents/staff-4.md` | `legal-review`（法務・適法性レビュー） |
| staff-5 | `.claude/agents/staff-5.md` | `ui-ux-review`（UI/UXレビュー・使い勝手） |
| staff-6 | `.claude/agents/staff-6.md` | `visual-design`（アイコン設計・アイコン集拡充・配色） |

> スキルは `.claude/skills/<名前>/SKILL.md` に置いた「その社員の手順書」。
> 該当する仕事のときに自動で参照されます。
