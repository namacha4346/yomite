# ボードゲームひろば（仮）運営チーム

このサイト（`hub/` のボードゲームひろば）を運営するための、AIエージェントによる
「会社」です。**メインエージェント1人＋サブエージェント3人**の体制で回します。

## 組織図

```
              ┌──────────────┐
   ユーザー ──▶│  secretary    │  メインエージェント（一流のキャリアウーマン秘書）
  （あなた）   │  段取り・進捗管理│  指示を受け取り、担当へ振り分け、進捗を管理し報告
              └──────┬───────┘
          ┌──────────┼──────────┐
          ▼          ▼          ▼
     ┌─────────┐┌─────────┐┌─────────┐
     │ staff-1 ││ staff-2 ││ staff-3 │
     │ 校正校閲 ││ ゲーム   ││ 宣伝広報 │
     │ のプロ   ││ 制作者   ││ ・SNS    │
     └─────────┘└─────────┘└─────────┘
```

## 役割分担

| エージェント | 役割 | 状態 |
|-------------|------|------|
| **secretary** | 一流のエグゼクティブ秘書（バリバリのキャリアウーマン）。受付・割り振り・進捗管理・品質の門番・報告。仕事ができて進捗管理に厳しい | 稼働中 |
| **staff-1** | 校正・校閲のプロ（元・大手出版社の編集長）。文章の質だけを審査（重複・表記ゆれ・構成・読みやすさ）。内容の正誤は見ない | 稼働中 |
| **staff-2** | プロのボードゲーム制作者（世界で活躍）。ルールの正確さ・抜け・例外・教える順番を検証。文章の巧拙は見ない | 稼働中 |
| **staff-3** | 宣伝・広報／マーケティングのプロ。お客さんを引きつけるキャッチコピーと、Instagram・X・Threads の SNS 運用が得意 | 稼働中 |

## 指示の流れ

1. **ユーザー → 秘書**：やってほしいことを秘書に伝える。
2. **秘書が整理**：曖昧な点を確認し、タスクに分解する。
3. **秘書 → 担当**：各タスクを適した担当へ、目的・成果物・制約つきで委任する。
4. **担当 → 秘書**：成果物と、判断に迷った点を返す。
5. **秘書 → ユーザー**：結論から簡潔に報告する。

## エージェントの実体

各エージェントは Claude Code のサブエージェントとして
`.claude/agents/` に定義しています（このファイルは人間向けの概要）。

| エージェント | 定義ファイル |
|-------------|-------------|
| secretary | `.claude/agents/secretary.md` |
| staff-1 | `.claude/agents/staff-1.md` |
| staff-2 | `.claude/agents/staff-2.md` |
| staff-3 | `.claude/agents/staff-3.md` |

## これから

- [x] staff-1 の役割を決める → 校正・校閲のプロ
- [x] staff-2 の役割を決める → プロのボードゲーム制作者（ルール検証）
- [x] staff-3 の役割を決める → 宣伝・広報／SNS のプロ
- [ ] 会社名を決める（今は「ボードゲームひろば（仮）運営チーム」）

> 役割を割り当てるときは、対応する `.claude/agents/staff-N.md` の
> `description` と本文を書き換えてください。
